# 🛒 Fresh Cart

Fresh Cart is a simple grocery shopping website designed using **pure HTML and CSS**. The project focuses on creating a clean and attractive e-commerce-style interface for browsing grocery products.

## ✨ Features

* 🏠 Home page
* 🛍️ Grocery product sections
* 🥦 Product categories
* 🖼️ Product images and cards
* 💰 Product pricing
* 🛒 Shopping-focused UI
* 🎨 Clean and simple design

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/janvi-jain/Fresh-Cart
```

### 2. Navigate to the Project

```bash
cd Fresh-Cart
```

### 3. Open the Project

Open `index.html` directly in your browser or use **Live Server** in VS Code.

## 🎯 Project Purpose

The purpose of this project is to practice the fundamentals of **HTML and CSS** by creating a grocery shopping website with product layouts, navigation, sections, cards, images, and styling.

## 📌 Project Highlights

* Built completely with HTML and CSS
* No JavaScript framework or library used
* Focused on frontend layout and styling
* E-commerce-inspired design
* **Desktop-focused and not responsive**
